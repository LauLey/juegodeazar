# ✊🖐✌ Piedra, Papel o Tijera

## Descripción

Piedra, Papel o Tijera es una aplicación interactiva desarrollada con **HTML, CSS y JavaScript**. El usuario juega contra la computadora, mientras el marcador se actualiza en tiempo real hasta que una de las dos partes alcanza 5 puntos y la partida finaliza.

Este proyecto me permitió reforzar habilidades de programación mediante la creación de una lógica de juego basada en eventos y en el control del estado de la aplicación.

## ✨ Características

- Juego contra la computadora.
- Marcador actualizado en tiempo real.
- Finalización automática de la partida al llegar a 5 puntos.
- Reinicio de la aplicación para jugar nuevamente.
- Habilitación y deshabilitación de elementos según el estado del juego.
- Flujo de juego basado en eventos del usuario.
